## D-AS-08 — Исправление метаданных прозрачности, раунд 1 (19.11.2026)

Для игровых ассетов зарезервирован контрольный chromaKey #FF00FF: цвет отсутствует в палитре игры и позволяет AC-03 проверять остатки фона и цветной ореол. Исходные промпты запрашивали прозрачный фон, поэтому это контрольный цвет проверки, а не утверждение о применении хромакея при генерации. Существующая альфа сохраняется; перекрашивание и новые генерации не нужны при problems=[]. Значение записано в игровой манифест и assets/game/PROMPTS.md; PROMPTS.md сохраняет настройку проверки после повторной штатной сборки, которая не переносит дополнительные поля.

Полнота определяется актуальным планом и D-GC-13: 87 id, в том числе три сцены вместо восьми прежних фонов. Ранее выявленные визуальные недостатки и неизвестная история исходных вызовов не объявляются исправленными метаданными. SDK, UI Kit и звук не меняются. Запись в docs/gdd/DECISIONS.md сделана по прямому указанию владельца для этого раунда.

Проверки раунда 1: npm run check выполнен один раз, FAIL: отсутствуют esbuild/sharp/ajv и другие локальные зависимости; галерея NOT_RUN, PLAYWRIGHT не задан. npm run assets -- --check: FAIL, sharp отсутствует. studio-gates asset-contract: FAIL, не заданы gates.art.budgetOfRoot и gates.asset-contract.fields; AC-03 в этом запуске не измерен из-за раннего выхода AC-01. Логи сохранены рядом. Никакие параметры гейта не придуманы.
