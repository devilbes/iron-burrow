# GAME BRIEF — Iron Burrow

Источник правды — `docs/gdd/00_MASTER.md`. Исследование — `docs/gdd/knowledge-base/research/` (references, audience, platform, monetization). Режим «Решай сам».

## Идея

**Iron Burrow** — онлайн-аркада для веба с видом сверху. Игрок ведёт **Burrower**, коренастый железный бур-танк, через подземные лабиринты из глиняного кирпича и стальных плит. Его задача — защитить светящееся **Burrow Core** внизу карты от волн **Rustbugs**, ржавых танков-жуков. Каждый выстрел выгрызает кирпич по четвертинке, поэтому игрок перестраивает лабиринт прямо в бою. Мигающие Rustbugs роняют усиления, а бустеры (Bubble Shield, Shockwave, Steel Fortress, Spare Hull) работают как аварийный запас. Формула классической аркады о защите базы 80-х пересобрана под короткие веб-сессии: стадия длится 2 минуты, 30 стадий в 3 главах, бесконечный режим Siege с лидербордом. Рекламы нет.

- **Хук:** «Классическая защита базы в лабиринте, стадии по 2 минуты, разрушается всё, а Core у тебя одно».
- **Жанр:** arcade — maze shooter / base defence, 2D (Canvas 2D + UI Kit), web, все три ориентации, `online: true`.

## Столпы

1. **Разрушаемый лабиринт — это тактика.** Каждый выстрел меняет карту: можно прорубить проход, а можно открыть Core.
2. **Одно Core, одна ошибка.** Одно попадание в Core означает поражение. Напряжение держится всю стадию, но сама стадия короткая (90–180 с).
3. **Честная аркада.** Без рекламы, таймеров и лутбоксов. Кампания проходится без покупок, бустеры дают страховку, а не пропуск.

## Аудитория

Casual–midcore веб-игроки 16–45 лет: ностальгирующие по аркадам 80–90-х и молодые игроки порталов. Устройства делятся примерно поровну между мобильным браузером и десктопом (Poki: ~48 % мобильных сессий). Подробно — `research/audience.md`.

## Core loop

`Lobby → Stage Map → Pre-stage (Spare Hull) → Stage: уничтожить 20 Rustbugs, сохранить Core → Stage Clear (звёзды, очки, бустер) → следующая стадия`.
Поражение → окно Defeat → continue за Spare Hull / покупка пака / повтор.
Мета: 30 стадий (3 главы) · Siege (открывается после стадии 5) с недельным лидербордом · 7-дневные ежедневные награды · магазин наборов бустеров.

## Длина сессии

6–15 мин = 3–6 стадий по 90–180 с. Это укладывается в типичные для веба 11–20 мин на игру (опрос Poki 2026).

## Монетизация

Только IAP через ManyPlay SDK (`iap`). Рекламы нет, валюты в MVP нет. Паки бустеров: Starter Crate 0.99 (разово), Hull Pack 1.99, Field Kit 4.99, Heavy Arsenal 9.99, Commander Cache 19.99. Точки показа: Shop, Defeat, Pre-stage (если Spare Hull = 0). Пока оплата не подключена, покупки тестовые. Разбор цен — `research/monetization.md`.

## Риски

1. **Тач-управление в landscape 844×390.** Клетка ~28 px, стик и FIRE по бокам поля. Если стик неточный, игрок уходит. Митигация: плавающий стик, квантование в 4 оси с гистерезисом, ранний плейтест на телефоне.
2. **Pay-to-win в Siege.** Бустеры разрешены, а результат идёт в лидерборд. Митигация: лимиты на забег, пометка «с бустерами», недельный сброс (рекомендация для разделов 13/16).
3. **Ощущение «продажи сложности».** Это главная жалоба в играх с бустерами. Митигация: ровная кривая без «стен», бустеры из наград, Defeat-окно без давления.
4. **Вес и скорость загрузки.** Игроки уходят после ~10 с загрузки. Цель (оценка): ≤ 5 МБ до старта стадии 1, остальное догружается.
5. **Узнаваемость формулы.** Игра близка к классической аркаде 80-х, поэтому нужен свой сеттинг (подземелье, Core, Rustbugs), свой арт и ни одного чужого названия или ассета. Действует список запретных слов из 00_MASTER.

## Допущения (приняты без ответа пользователя, режим «Решай сам»)

- Платформа — только web; ориентации portrait 390×844, landscape 844×390, desktop 1440×900 равноправны.
- Базовый язык — en, другие локали — только на шаге локализации.
- Рекламы нет вообще; монетизация — только наборы бустеров за реальные деньги по ценам из 00_MASTER §12 (USD).
- В MVP нет валют: награды — бустеры, звёзды, место в лидерборде. Валюта Scrap и Garage отложены на следующий этап.
- Стартовый подарок новому игроку — по 2 каждого бустера.
- Кампания — 30 стадий в 3 главах, звёзд-гейтов нет. Siege открывается после стадии 5.
- Лидерборды: `siege_best` (недельный) и `campaign_score` (all-time).
- Ежедневные награды: цикл 7 дней с семантикой календаря платформы.
- Бустеры в Siege разрешены с лимитами ×2 на забег.
- Игра онлайн, симуляция стадии клиентская, без live-мультиплеера.
