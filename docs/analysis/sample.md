# Образец и идея (вход шага анализа)

Переменные запуска (форма «Новая игра»):

| поле | значение |
|---|---|
| Название | Iron Burrow |
| Жанр | arcade |
| Образец | классическая аркада 80-х о защите базы танком (название образца входит в запретные слова и в документах не употребляется) |
| Описание образца (механика) | танк в лабиринте из кирпича и стали, защита штаба, волны вражеских танков, выпадающие усиления |
| Ссылка на стор / package | нет |
| Запретные слова | заданы в переменных запуска; в документах, игре, ассетах и описаниях не воспроизводятся |
| Решай сам | да |
| Язык ТЗ | русский; базовый язык игры — en |
| MVP / платформа | по умолчанию шаблона → web, три ориентации |
| База знаний / ресёрч | нет (короткое исследование — docs/gdd/knowledge-base/research/) |

Отдельного текста идеи, кроме полей формы, во входе шага нет; идея восстановлена из названия, жанра и описания механики образца. Переосмысление: подземный сеттинг («нора»), штаб → Burrow Core, вражеские танки → Rustbugs (жуки из лома).

Что берём из механики образца: сетка 13×13 с разрушаемым по четвертям кирпичом и прочной сталью; одна база внизу по центру, одно попадание — поражение; 20 врагов на стадию, ограничение живых на поле, спавн сверху; четыре типа врагов (быстрый, базовый, стрелок, бронированный); мигающие враги-носители усилений; прокачка пушки до пробития стали.

Что меняем: свой сеттинг, имена и графика; стадии короче и мягче для веба; бустеры-расходники и продолжение за Spare Hull; звёзды за прохождение без потерь; режим Siege с лидербордом; ежедневные награды и магазин наборов (без рекламы).
