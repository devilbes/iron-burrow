# 22 — VFX, анимация, ощущение (`fx.`)

Источник событий и чисел — `00_MASTER.md` §5–§6. Эффекты поля рисует модуль `fx` в Canvas 2D поверх слоя тайлов; эффекты UI — CSS-анимации компонентов UI Kit. Длительности в ms, единица расстояния — клетка поля (`cell`, §5); пиксели = доля × `cell`. Звук к событиям — §23 (те же id событий).

## `fx.principles`

- Читаемость важнее зрелищности: эффект никогда не скрывает пулю, врага или Ядро дольше 1 кадра; частицы рисуются под пулями.
- Первый визуальный отклик на ввод — в ближайшем кадре (≤ 50 ms, см. `fx.genre_targets`).
- Палитра §21: игрок и его пули — teal/белый; враги — ржавый + кислотно-зелёные глаза; огонь/взрывы — магма-оранжевый → жёлтый; сталь — холодные голубые искры; кирпич — терракотовая крошка.
- Hitstop (заморозка симуляции) — только на убийствах и событиях Ядра, ≤ 60 ms, не суммируется (берётся максимум).

## `fx.shake` — тряска с затуханием

- Смещение камеры: `offset(t) = A · e^(−t/τ) · n(t)`, где `n` — 2D value-noise 30 Гц, `τ = длительность / 3`; по окончании — ровно 0.
- Наложение: новая тряска берёт `max(A_текущая_остаточная, A_новая)`, не суммируется. Потолок `A ≤ 0.35 cell`.
- Тряска сдвигает только слой поля; HUD и окна неподвижны. Поворотов нет.
- Тач-устройства: дополнительно `sdk.device.haptics` по таблице §23 (только kill_brute, player_death, core_destroyed, booster_shockwave).

## `fx.particles` — лимиты

- Пул частиц фиксированный, без аллокаций в кадре: desktop 320, mobile (`pointer: coarse`) 192. Сверх лимита — новые частицы вытесняют самые старые; обломки ≤ 1 кадра жизни не создаются.
- Пер-событие лимиты — колонка «Частицы» каталога; для `quake`/`shockwave` — общий лимит события 120 (desktop) / 72 (mobile), распределяется по взрывам.
- Если p95 кадра > 20 ms 3 с подряд — уровень эффектов «low»: частицы ×0.5, дым и остовы выключены (D-22-01).

## `fx.reduced_motion` — Reduce Motion

Включается `settings-motion` (S14) или `prefers-reduced-motion: reduce` по умолчанию.
- Тряска = 0; hitstop остаётся (это ритм, не движение), замедление `stage_clear` → простой фейд.
- Вспышки на весь экран и виньетки заменяются фейдом цвета ≤ 30 % альфы за 200 ms; ничего не мигает чаще 3 Гц в любом режиме.
- Частицы ×0.3, обломки без вращения; летящие к HUD иконки — фейд на месте + пульс счётчика.
- UI: окна — только fade 150 ms; `fx.reward_reveal` — все карточки сразу, fade 200 ms.
- Геймплейная информация не теряется: таймеры бустеров, мигание носителей и истекающих power-up заменяются пульсом прозрачности 1 Гц.

## `fx.genre_targets` — Genre targets

| Цель | Порог | Measured by |
|---|---|---|
| input → first visual feedback (выстрел `fx.shot`, сдвиг танка) | ≤ 50 ms | `performance.now()` события ввода → кадр, где `game-field` получил `data-fx-ack="fx.shot#N"` (+ `performance.mark('fx:<id>#N')`) |
| hit → эффект попадания (`fx.hit_*`, `fx.kill_*`) | тот же кадр, что и логическое попадание (0 кадров задержки) | тик симуляции попадания vs `data-fx-ack` |
| UI tap → отклик кнопки (`fx.ui_button`) | ≤ 50 ms | pointerdown → смена transform |
| frame time | p95 ≤ 16.7 ms desktop, ≤ 33 ms mobile 4×CPU throttle | трасса 120 с стадии |
| боевая плотность | первый вражеский спавн ≤ 3 s от старта стадии, первый контакт (враг в поле зрения/выстрел) ≤ 10 s | лог событий симуляции |
| длительность стадии | 90–180 s у бота-эталона на стадиях 1, 10, 20 | лог `stage_end` |
| hitstop | 30–60 ms на убийствах, 120 ms на Ядре; не более 1 активного | лог fx |
| частицы | никогда > лимита пула | счётчик пула, max за прогон |

Seeds: `1`, `7`, `42` — RNG симуляции (спавны, дропы power-up по весам §5, ИИ) детерминирован от seed; seed задаётся только в тестовом окружении (D-22-02). Каждая цель меряется на всех трёх seed и трёх ориентациях; протокол прогона — `40_qa_acceptance.md` `qa.genre_targets`.

## Решения

- D-22-01: авто-понижение качества эффектов при просадке кадра; обратно в «high» не возвращается до конца стадии.
- D-22-02: seed RNG выставляется только в env `test` (параметр запуска для gate-скрипта); в prod seed случайный.
- D-22-03: `data-fx-ack` пишется только для событий из `fx.catalog` с префиксом `fx.shot`, `fx.hit_`, `fx.kill_`, `fx.pickup_`, `fx.booster_`, `fx.player_`, `fx.core_`, `fx.stage_clear` — UI-эффекты не пишутся.
- D-22-04: hitstop Ядра 120 ms — единственное превышение 60 ms; осознанно для веса поражения.
- D-22-05: power-up `quake` и бустер Shockwave визуально различаются: quake — бурая земляная волна, Shockwave — teal-кольцо игрока.
