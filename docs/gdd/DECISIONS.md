# Журнал решений ГДД (режим «Решай сам»)

Владелец не опрашивался; каждое решение принято по умолчанию с обоснованием. Решения разделов (D-10-NN … D-40-NN) записаны в самих разделах; здесь — сквозные.

| ID | решение | обоснование |
|---|---|---|
| D-00-01 | Таргет web, ориентации portrait 390×844, landscape 844×390, desktop 1440×900, orientation_fixed = false | Владелец не ограничил платформу/ориентацию; поле квадратное 13×13 — полноценно играется в обеих ориентациях (портрет: поле сверху во всю ширину, управление снизу; ландшафт/десктоп: поле по центру, HUD и управление по бокам) |
| D-00-02 | Сеттинг «под землёй»: игрок — танк-бур Burrower, база — Burrow Core, враги — Rustbugs | Название Iron Burrow; уход от чужих IP образца (штаб-орёл, имена, графика) |
| D-00-03 | Поле 13×13 клеток, клетка = 2×2 четверти разрушения | Проверенная читаемая структура жанра; разрушение кирпича по четвертям даёт тактику «проковырять стену» |
| D-00-04 | Стадия = 20 врагов, 3 жизни на стадию, одно попадание в Core — поражение | Длительность стадии 90–180 с под веб-сессию; жизни не переносятся между стадиями — мягче для казуальной аудитории |
| D-00-05 | 30 стадий кампании в 3 главах + бесконечный режим Siege (открывается после стадии 5) | «Полноценная игра, не концепт»: кампания даёт прогрессию и звёзды, Siege — реиграбельность и смысл лидерборда |
| D-00-06 | Валют в MVP нет; мягкая валюта Scrap (гараж-апгрейды, коллекция скинов корпуса, бонусные главы) — следующий этап | Правило экономики: траты для валюты придуманы, но платформа пока не публикует правила обмена и стартовый баланс → первая версия без валюты; твёрдой валюты нет вовсе |
| D-00-07 | Расходуемые предметы — 4 бустера (Bubble Shield, Shockwave, Steel Fortress, Spare Hull) | Механика сама их расходует; их выдают награды уровней, ежедневные награды и продаёт магазин |
| D-00-08 | Стартовый грант 2× каждого бустера — отдельной наградой | Ограничение инвентаря платформы: награды не смешиваются с твёрдой валютой (её нет), грант не должен отклоняться целиком |
| D-00-09 | Продолжение после поражения — только за Spare Hull (1 раз на стадию), без рекламы | Рамки потока: рекламы нет; continue-оффер через расходник и покупку набора |
| D-00-10 | Паки: 0.99 / 1.99 / 4.99 / 9.99 / 19.99 USD | Рыночная лестница цен веб/мобильных казуальных игр (см. knowledge-base/research/monetization.md); значения — в конфигах iap.*, меняются без сборки |
| D-00-11 | Лидерборды: siege_best (неделя) и campaign_score (всё время) | Leaderboards подключается, т.к. механика даёт счёт; еженедельный сброс — свойство доски, без отдельного liveops |
| D-00-12 | Не используются: ads (рамки потока), realtime (нет живого мультиплеера/пушей в MVP), scheduling (beta; недельный цикл даёт доска) | Итоговое решение по сервисам — docs/gdd/services-matrix.md (шаг «Сервисы платформы») |
| D-00-13 | Базовый язык en, languages [en] | Рамки потока; остальные локали — шаг локализации |
| D-00-14 | Палитра холодный сланец/сталь + оранжевая магма + кислотно-зелёный | Аркаде нужен контраст и читаемость на скорости; отличие от типовой тёплой казуалки |
| D-00-15 | Текста идеи кроме полей формы нет — идея восстановлена из названия, жанра и описания образца | Режим «Решай сам»; см. docs/analysis/sample.md |
