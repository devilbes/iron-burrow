# 16 — Монетизация (`mon.`)

Источник — `00_MASTER.md` §12. Итог по сервисам — `docs/gdd/services-matrix.md` (строки `iap`, `inventory`, `configs`; строка `ads` — исключён).

## mon.model — модель

- **Только IAP за реальные деньги.** Рекламы нет нигде: ни rewarded, ни interstitial, ни баннеров; модуль `ads` не подключается, элемент `ad-banner-slot` UI Kit не используется (D-16-01).
- Продаются только наборы бустеров (расходуемые предметы, 15 `meta.items`). Валют нет.
- Цены — USD, стартовые; хранятся в `iap.packs`, меняются без сборки. На экране показывается цена из офферов сервиса iap (локализованная строка платформы), а не число из конфига.

Строка Starter Crate внутри Defeat — не авто-окно и кулдаун не расходует.

## mon.defeat — точный порядок окна Defeat (S08)

1. Core разрушен или жизни = 0 → симуляция остановлена, эффект поражения (22 `fx.`), затем окно Defeat через очередь окон UI Kit. Таймера обратного отсчёта нет (D-16-04).
2. **Continue Spare Hull** (первым, главная кнопка): виден, если continue в этой стадии/забеге ещё не использован.
   - `bst_hull` ≥ 1 → кнопка «Continue (Spare Hull ×1)» активна → списание 1 `bst_hull` через inventory → +2 жизни, Core восстановлен (если разрушен), игрок с щитом появления 3 с, стадия продолжается.
   - `bst_hull` = 0 → кнопка неактивна, с подписью «No Spare Hull».
3. **Оффер** (под continue): только если continue доступен и `bst_hull` = 0 — Hull Pack 1.99 и Starter Crate 0.99 (если не куплен). После успешной покупки балансы перечитываются, кнопка continue становится активной; покупка continue сама не тратит — игрок жмёт continue (D-16-05).
4. **Retry / Stage Map** (внизу): Retry — заново та же стадия через Pre-stage (бустеры не тратятся); Stage Map — выход на карту. В Siege вместо Retry/Map — переход к S09 Siege Result.
5. Если continue уже использован — шаги 2–3 скрыты, сразу шаг 4.

## mon.errors — ошибки, отмена, офлайн

| ситуация | поведение |
|---|---|
| нет сети (по `sdk.device.network`) | кнопки покупки неактивны с текстом «No connection»; магазин открывается со списком из последних полученных офферов, покупка невозможна |
| отмена игроком | тихий возврат в исходное окно, без сообщения об ошибке, без повторного показа оффера |
| ошибка оплаты / сервиса | S11 Purchase result с ошибкой и кнопкой «Try again»; предметы не выдаются |
| покупка в обработке / обрыв связи во время покупки | S11 «Processing»; после восстановления — перечитать балансы inventory; выдача только по факту на сервере |
| успех | S11 со списком полученных предметов, обновление HUD-счётчиков бустеров, событие `an.purchase_result` |
| оффер недоступен (нет в ответе iap) | пак скрыт из витрины и плейсментов |

Форма результата `iap.purchase` (поля успеха/отмены/ошибки) — уточняет интеграция.

## mon.grant — выдача

`iap.purchase` → сервис iap подтверждает платёж → сервис начисляет предметы в inventory по составу оффера (настраивает services-publish) → игра перечитывает `inventory.balance`. Клиент никогда не начисляет предметы сам и не хранит покупки локально (D-16-06).

## mon.test — тестовые покупки

Пока владелец не подключил оплату, все покупки — тестовые (среда `test` в `platform.json`): платёж не списывается, предметы начисляются как при реальной покупке. В S10/S11 показывается пометка «Test purchase», если платформа сообщает тестовый режим (способ определения — уточняет интеграция). Переключение на реальные платежи — действие владельца в Студии, без сборки игры.

## mon.compliance — комплаенс

- Состав каждого пака фиксирован и показан до покупки; случайных наград (лутбоксов) нет.
- Цена — из сервиса iap, с валютой платформы; налоги, чеки, возвраты — на стороне платформы.
- Нет таймеров давления, «последних шансов» и скрытых подписок; Starter Crate не показывается в стадии.
- Покупка всегда подтверждается окном платформы; случайное нажатие не списывает деньги.
- Игра проходима без покупок (прогноз 15 `meta.forecast`); преимущество в Siege-рейтинге ограничено лимитами бустеров за забег.
- Запретные слова из переменных запуска (00_MASTER, шапка) не используются в названиях паков и описаниях.

## Решения

| ID | решение |
|---|---|
| D-16-01 | Рекламы нет совсем: модуль ads и слот баннера UI Kit не используются |
| D-16-02 | One-time для Starter Crate обеспечивает сервис iap; клиент только скрывает купленный оффер |
| D-16-03 | Оффер на Defeat показывается только когда continue доступен и `bst_hull` = 0 |
| D-16-04 | В окне Defeat нет таймера обратного отсчёта |
| D-16-05 | Покупка на Defeat не применяет continue автоматически |
| D-16-06 | Выдача только сервером (iap → inventory); клиент лишь перечитывает балансы |
| D-16-08 | В S10 у Field Kit бейдж `Best value` (`ui.shop.best_value`); на S08 под Hull Pack — ссылка «More in Shop» на S10 (рекомендация ресёрча: Hull Pack дороже за штуку) |
| D-16-07 | Авто-окно Starter Crate: триггеры первое поражение / первое прохождение стадии 3, кулдаун 24 ч, максимум 3 авто-показа |
