# PLATFORM_SERVICES — каталог модулей SDK платформы ManyPlay (Iron Burrow)

Источник — только MCP `manyplay` (19.11.2026): `sdk.modules.list` (revision 1, SDK `1.0.0-rc.30`, targets `web`), справочник методов `manyplay://docs/sdk/reference/methods` и страницы модулей (`docs.get` / `docs.search`). Ничего вне ответа MCP не записано.

Модулей в `sdk.modules.list`: **11**. В составе приложения сейчас выбран только `ui-kit` (`selection: required`); остальные — `optional`, `selected: false`; их включает шаг flow-plan через `sdk.modules.set` по `docs/gdd/services-matrix.md`.

## 2. Возможности ядра `@manygamescorp/core` (не записи каталога, работают всегда)

Не входят в `sdk.modules.list` и не добавляются в `sdk.modules.set` (id `profile` — core-owned, иначе `SDK_CONFIG_INVALID`). Источник — `manyplay://docs/sdk/reference/methods`.

| возможность | назначение | методы | статус |
|---|---|---|---|
| core | загрузка SDK, жизненный цикл модулей | `createSdk`, `sdk.boot`, `sdk.destroy`, `sdk.getModule`, `sdk.state` | есть |
| auth (ManyPlay ID) | сессия игрока: гость, email-код, соцвход, связки, ник | `sdk.auth.init` и методы модуля auth | есть |
| portal | открыть ManyPlay ID, fullscreen, выход из игры | методы модуля portal | есть |
| profile | профиль игрока, поля, публичные профили | `sdk.profile.get`, `update` | есть |
| configs | удалённые конфиги по scope/key с A/B, сегментами, фильтрами | `sdk.configs.fetch`, `get`, `getScope`, `refresh` | есть |
| context / filters | факты игрока для фильтров конфигов | методы context, filters | есть |
| time | серверное время — единственные часы логики | `sdk.time.now()` | есть |
| l10n / locale | строки, плюрали, выбор локали | `sdk.l10n.t`, `sdk.l10n.locale` | есть |
| device | экран, сеть, хаптика, жизненный цикл | `sdk.device.info`, `screen`, `haptics`, `network` | есть |
| analytics | события игры, безопасный no-op без адаптера | `sdk.analytics.sendEvent` | есть |
| bus | шина событий SDK | `sdk.bus.on`, `once` | есть |
| uiState | отчёт о видимом экране и полноэкранных окнах | методы uiState | есть |
