# Добавить картинки и звук

> Рецепт. Фрагменты с пометкой «образец» — код для игры, в `src/` шаблона его нет.

## Куда класть
| Что | Где |
|---|---|
| картинки экранов игры | `assets/images/` |
| звуки и музыка | `assets/audio/` |
| арт скина окон (рамки, фактуры, иконки) | `assets/skin/` — [custom-window-skin.md](custom-window-skin.md) |
| исходники (слои, макеты, референсы) | `design/` или `assets/source/` — в архив сборки на платформе не попадают (`.buildignore`) |

`npm run build` копирует `assets/` в `dist/assets/` (файлы `README.md` пропускает). Имена файлов —
латиница, цифры, `-` и `_`, без пробелов.

## Картинки: только 2x, остальное — командой
- Рисовать **только картинку 2x**: `<имя>-2x.png` (или `-2x.webp`, `-2x.jpg`). Обе стороны — чётные.
- Файл 1x (`<имя>.png`) **не создавать и не править руками**. Его делает команда.
- После того как картинки добавлены или изменены, один раз: `npm run assets`.

| Команда | Что делает |
|---|---|
| `npm run assets` | для каждой `<имя>-2x.<ext>` в `assets/` (кроме `assets/source/`) пишет `<имя>.<ext>` ровно вдвое меньше: пиксель — среднее четырёх с весом по прозрачности, без тёмной и цветной каймы. Верные файлы не переписывает |
| `npm run assets -- --webp` | ещё `<имя>-2x.webp` и `<имя>.webp` из каждого PNG, без потерь; `--webp=80` — с потерями, качество 80. WebP, который уже лежит рядом с PNG 2x, дальше обновляется и без опции |
| `npm run assets -- --defringe assets/game/hero-2x.png` | убирает ореол цвета-ключа с прозрачных краёв картинки 2x (переписывает её) и делает 1x. Ключ — зелёный `00ff00`; другой — `--defringe=ff00ff`. Ширина края — 4 пикселя, `--defringe-width=6`. Без имён файлов — все картинки 2x |
| `npm run assets -- --check` | ничего не пишет; код 1 и все проблемы разом. Входит в `npm run check` |

Что считается проблемой:
- сторона 2x нечётная — исправить картинку 2x (команда называет ближайший чётный размер), сама не округляет;
- 1x нет, она не вдвое меньше 2x или отличается от уменьшенной 2x (устарела или правлена руками) —
  `npm run assets`;
- картинка без пары 2x (`<имя>.png` без `<имя>-2x.png`) в `assets/images/`, `assets/game/`,
  `assets/ui/` — нарисовать 2x и переименовать.

`--defringe`: цвет-ключ не должен встречаться в самой картинке у края (зелёный лист — на ключе
`ff00ff`); свечения и стекло у края — не обрабатывать, назвать только нужные файлы.

Где пара обязательна: картинки экранов и интерфейса игры — `assets/images/`, `assets/game/`,
`assets/ui/`. В `assets/skin/` и любой другой папке `assets/` картинка может быть одним файлом
(`scene.webp`, `coins.png`, атласы `icons-recolored*.png`); если же там лежит `<имя>-2x.<ext>`, это
пара с теми же проверками.

## Потолок веса
Потолки задаёт замысел игры; впишите их сюда, когда они известны:
- одна картинка — не больше ___ КБ;
- один звук — не больше ___ КБ, музыкальная петля — не больше ___ КБ;
- весь `assets/` — не больше ___ МБ.

Размер картинки 2x — не больше, чем она занимает на экране при плотности 2×.

## Картинка на экране
URL файла из `assets/` даёт `src/assets.ts` (не зависит от адреса страницы):
```ts
export function assetUrl(path: string): string {
```
Образец, экран рисует картинку видом UI Kit:
```ts
import { assetUrl } from '../assets.js';
view('img', { src: assetUrl('images/background.webp'), alt: '', class: 'board-bg' });
```
В CSS экрана — `background-image:url(${assetUrl('images/background.webp')})` в строке стилей.
Видимый текст на картинках не рисуют: текст — по ключам локализации.

## Звук
В установленных пакетах проигрывателя звука нет: UI Kit и модули SDK звук не играют. В ядре есть
только `sdk.device.audio` (`state`, `onChange`, `session('ambient' | 'playback')`), и на вебе
состояние звука недоступно (README `platform-web`). Окно настроек UI Kit умеет переключатели
`sound` и `music` (`values` окна `ui.settings`), но окно настроек шаблона их не показывает
(`src/shell/windows/standard.ts`), так что выключить звук игрок пока не может.

Поэтому звук — средствами браузера. Образец:
```ts
import { assetUrl } from '../assets.js';

const click = new Audio(assetUrl('audio/click.mp3'));
const music = Object.assign(new Audio(assetUrl('audio/music.mp3')), { loop: true, volume: 0.5 });

/** Короткий звук; браузер играет звук только после первого касания или клика игрока. */
export function playClick(): void {
  click.currentTime = 0;
  void click.play().catch(() => undefined);
}

/** Музыка: вызвать в обработчике первого действия игрока (например, «Play»). */
export function startMusic(): void {
  void music.play().catch(() => undefined);
}

// На скрытой вкладке — пауза.
document.addEventListener('visibilitychange', () => {
  if (document.hidden) music.pause();
  else if (music.currentTime > 0) void music.play().catch(() => undefined);
});
```
Формат звука — MP3 или AAC (`.m4a`): их играют все браузеры.

## Как проверить
`npm run assets -- --check` → пары верны; `npm run build` → файлы лежат в `dist/assets/`; в браузере картинки видны, в консоли и в сетевом
журнале нет ошибок 404.
