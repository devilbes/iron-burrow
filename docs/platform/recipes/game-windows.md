# Окна игры: результат, пауза, поражение

Свои окна игры — уровень пройден, уровень не пройден, пауза, знакомство с бустером,
подтверждение — открываются через `ctx.window.open` и выглядят как окна сервисов (магазин,
ежедневные награды): окно кита в скине игры. Рамка, плашка заголовка, крестик, кнопки и
затемнение на весь экран — от кита и скина; игра даёт заголовок, кнопки и своё содержимое.

**Правило: своей вёрстки модальных окон нет.** Экран не рисует карточку окна, свой фон-затемнение,
свои кнопки окна, `role="dialog"`, `aria-modal`, `<dialog>`, слой `position: fixed` или
`position: absolute` с `inset: 0`. Иначе в игре два вида окон, а затемнение экрана останавливается
на краях области экрана: оболочка рисует экран в слоте с `contain: paint`, и любой «фиксированный»
слой экрана ограничен этим слотом — топбар и поля сцены остаются светлыми. Проверка —
`tests/screens-modals.test.mjs` (ниже).

## Окно: `ctx.window.open`
```ts
const shown = ctx.window.open({
  title: ctx.t('screen.result.title'),                 // текст плашки заголовка
  header: { stars: result.stars },                     // картинка кита над содержимым: 0…3 звезды и/или `icon`
  body: (root) => mountView(root, 'result', () =>      // содержимое игры — её DOM
    view('ul', { class: 'result' },
      view('li', {}, view('span', {}, ctx.t('screen.result.score')), view('b', {}, String(score)))),
    { styles: RESULT_CSS }),                           // свои правила — только переменные темы
  actions: [                                           // кнопки кита, до трёх, по порядку
    { id: 'next', label: ctx.t('screen.result.next') },                       // первая — основная
    { id: 'menu', label: ctx.t('screen.result.menu'), variant: 'secondary' },
  ],
  dismissible: false,                                  // без крестика, Esc и нажатия на затемнение
});
const picked = await shown.result;                     // 'next' | 'menu' | 'close'
```
| Поле | Что |
|---|---|
| `title` | заголовок окна (`ctx.t(key)`) |
| `header` | `{ icon?, stars? }` — картинка над содержимым, рисует кит (звёзды рейтинга, значок скина) |
| `text` | строка текста, которую рисует кит (подтверждению больше ничего не нужно) |
| `body(root)` | содержимое игры в рамке окна; рисовать `mountView` из `src/screens/ui.ts` (своя shadow root с темой), возвращать функцию снятия |
| `actions` | кнопки кита: `{ id, label, variant? }`, `variant` — `primary` (по умолчанию первая), `secondary`, `text`. Без кнопок кит ставит «Continue», результат `close` |
| `dismissible` | `false` — игрок выбирает только кнопкой |

`result` — `id` нажатой кнопки или `close` (крестик, Esc, затемнение, `close()` тикета, уход с
экрана). Любая кнопка закрывает окно. Окна, открытые экраном, закрываются, когда экран уходит.
Окно поверх окна игры (пауза → «Выйти из уровня?») — можно, до трёх сразу; нижнее затемняется.

Шаблон показывает это на заглушке: «Close» экрана игры спрашивает «Leave the level?» окном игры
(`src/screens/game.ts`). Свой экран игры заменяет заглушку вместе с этим окном и его строками
(`screen.game.leave.*` — `tests/strings.test.mjs` напомнит о неиспользуемых ключах).

Как устроено (`src/shell/windows/game.ts`): окно — компонент `popup` кита
(`@manygamescorp/ui-kit/services/popup`, тот же, что у `ui.popup`), поэтому лист `popup` скина,
`COMMON` и `theme.css` одевают его так же, как остальные окна; у окна `data-popup-variant="game"` —
крючок, если скину нужно выделить окна игры. Содержимое игры попадает в окно через `<slot>`.
Окно — `popupKind: 'alert'`: высота по содержимому; в ландшафте телефона картинка заголовка слева,
содержимое и кнопки справа (`layout: 'landscape'` кита).

## Затемнение — на весь экран
Окна кита и окна игры открываются в слое окон оболочки (`[data-part=popup]`); затемнение — его
`::before` с `position: fixed; inset: 0` и цветом `--mp-overlay`, который сток выводит из
`--mp-card-overlay` (`src/skin/theme.css`). Оно от края до края окна браузера, топбар и HUD — под
ним, остальная оболочка на время окна неактивна. Цвет затемнения — только переменная
`--mp-card-overlay` в `theme.css`, литералов нигде.

## Слой без окна: `ctx.overlay`
Подсказка обучения, «прожектор» на плитку, вуаль загрузки — не окна, но тоже поверх всего экрана:
```ts
const tip = ctx.overlay({
  dim: true,                                            // затемнение --mp-card-overlay (по умолчанию)
  draw: (root) => mountView(root, 'tip', () => view('p', { class: 'hero-title' }, ctx.t('screen.tip.tap'))),
});
// …
tip.remove();
```
Слой — дочерний элемент корня оболочки (`.mpg-shell`), `position: fixed; inset: 0`, над топбаром
и HUD, под окнами (правило `[data-part=game-overlay]` в `src/shell/skin.ts`). Пока он есть, нажатия
берёт он. Уходит вместе с экраном. Рисовать в `root` (`draw`) — `mountView`; вырез «прожектора» —
своим содержимым слоя (`dim: false` и своя маска переменными темы).

## Очерёдность с окном награды
Награда за уровень приходит выдачей сервера после ответа на конец уровня; её показывает окно
награды кита (`ui.reward`, триггер `inventory:items:granted`). Очередь окон SDK награду не
задерживает (открывает сразу, поверх всего), поэтому оболочка ставит правило
(`src/shell/windows/order.ts`): **окно игры и окно награды не стоят одно поверх другого** — то, что
попросили вторым, ждёт закрытия первого и открывается сразу после. Игра открывает окно результата
сразу по ответу `endLevel`, выдача приходит позже, значит порядок такой: **сначала результат,
награда — сразу после закрытия окна результата** (кнопкой «Дальше», «В меню» или крестиком).
Если окно награды уже открыто (выдача пришла раньше), окно игры ждёт его закрытия. Без таймеров:
только закрытие самих окон. Ждать награду в коде игры не нужно.

## Проверка
- `npm run test:unit`: `tests/window-order.test.mjs` — порядок с окном награды;
  `tests/screens-modals.test.mjs` — в `src/screens/**` нет своей вёрстки окна: `role` dialog,
  `aria-modal`, `<dialog>`, `showModal()`, `position: fixed`, `position: absolute` на весь размер
  (`inset: 0`, все четыре стороны 0, `100vw`/`100vh`). По умолчанию — отчёт (`# …` в выводе),
  `SCREENS_STRICT=1` — провал.
- Галерея скина (`tests/skin-gallery.mjs`): вид `game-window` — окно через `ctx.window.open` с
  тестовым содержимым (звёзды, строки счёта, две кнопки), `game-overlay` — слой `ctx.overlay`. Во
  всех видах с окном или слоем, в 390×844, 844×390 и 1280×720: каждое затемнение равно окну
  браузера (±1 px) и топбар под ним; окно игры — диалог кита (`.dialog[role=dialog]` компонента
  `popup`), заголовок в шапке, кнопки кита, содержимое игры внутри рамки
  (`tests/skin-gallery/modal-layers.js`).
- `tests/browser-startup.mjs`: «Close» заглушки → окно игры (диалог кита, текст содержимого),
  затемнение на весь экран в 1280×720, 844×390, 390×844; «Stay» оставляет уровень, «Leave» —
  главный экран; то же затемнение у каждого окна сервисов.
