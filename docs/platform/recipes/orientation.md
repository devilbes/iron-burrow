# Ориентация игры

Игра, жанру которой нужна одна ориентация, в другой не играется: платформер с боковой прокруткой
в портрете — узкая полоса с кнопками, по которым не попасть. Ориентация — решение дизайна игры,
его принимают по жанру и механике и объявляют один раз.

## Объявление
`src/screens/index.ts`:
```ts
export const ORIENTATION: GameOrientation = 'landscape';   // 'any' | 'landscape' | 'portrait'
```
| Значение | Когда |
|---|---|
| `'landscape'` | боковая прокрутка, раннер, гонка, широкое поле, управление двумя руками |
| `'portrait'` | головоломка одной рукой, поле «три в ряд», карты, слияние |
| `'any'` | только если каждый экран и сам уровень разложены под обе ориентации (так поставляется шаблон) |

Больше игра ничего не пишет: экрана «поверните устройство», определения устройства и блокировки
поворота в игре и в `src/shell/` нет — это делает SDK.

## Что делает SDK
`src/boot/start.ts` передаёт `ORIENTATION` в `createSdk` (`orientation`). SDK с этой опцией:
- на телефоне или планшете, который держат иначе, закрывает игру экраном «Поверните устройство»
  в скине игры (UI Kit; текст — ключи `kit.rotate.*`, вид — лист `rotateScreen` скина) поверх
  всего, включая окна и экран загрузки; после поворота экран уходит, страница не перезагружается,
  состояние сохраняется;
- сообщает состояние событием `sdk:orientation:changed` (`required`, `current`, `blocked`);
- там, где браузер это позволяет (страница во весь экран на Android), дополнительно блокирует
  поворот. На iOS блокировки в вебе нет — остаётся экран.

Правило «устройство в руках» — у SDK, не у игры: основной указатель — палец (`pointer: coarse`) и
короткая сторона физического экрана не больше 1024 px. Размер окна браузера не участвует: узкое
окно на компьютере игру не закрывает.

**Пока SDK без этой опции** (в `vendor/@manygamescorp/core/dist/` нет `orientation-guard.d.ts`;
так в 1.0.0-rc.30), объявленная ориентация не применяется: `createSdk` опцию пропускает, экрана
поворота нет, игра открывается в любой ориентации. После обновления SDK всё включается без правок
игры.

## Пауза: `ctx.onSuspend`
Пока игрок не может играть, уровень стоит: таймер, физика, звук.
```ts
const off = ctx.onSuspend((suspended) => {
  if (suspended) { loop.stop(); music.pause(); } else { loop.start(); void music.play(); }
});
```
`suspended` — `true`, пока вкладка или приложение в фоне (`app:lifecycle:changed`, работает уже
сейчас) или устройство держат не в ориентации игры (`sdk:orientation:changed`, с SDK, в котором
это событие есть); `false` — когда обе причины ушли. Поставленный во время паузы обработчик сразу
получает `true`. Обработчики экрана снимаются вместе с экраном (`src/shell/suspend.ts`). Своих
подписок на `visibilitychange` и на поворот экрана игра не делает.

## Настройка приложения
У приложения на платформе есть своя настройка ориентации — `orientation` в `platform.json`. Игра
её не меняет (`platform.json` не правится): значение задаётся на платформе и должно совпадать с
`ORIENTATION`. Если настройка называет ориентацию, SDK берёт её; `ORIENTATION` работает, пока в
настройке `any`.

## Проверка
`npm run test:unit`, `tests/orientation.test.mjs`:
- `ORIENTATION` — одно из трёх значений и передаётся в `createSdk`;
- `orientation` в `platform.json` не `any` и не равно `ORIENTATION` — провал;
- `ORIENTATION` не `any`, а в `platform.json` `any` — строка `NOTICE` в выводе: настройку
  приложения нужно поменять на платформе; это не провал;
- `ctx.onSuspend`: пауза по любой из двух причин, продолжение — когда ушли обе.
