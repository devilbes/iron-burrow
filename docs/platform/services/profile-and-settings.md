# Профиль, настройки, вход ManyPlay ID

Кнопки в топбаре: профиль слева, настройки справа. Клик сообщает элемент `hud:profile` /
`hud:settings` (`src/boot/ids.ts`), триггер `ui.windows/main` открывает окно.

## Профиль
Триггер открывает окно `main` модуля `profile-ui`, которого в rc.30 нет, поэтому
`src/shell/windows/player.ts` регистрирует его и показывает карточку игрока:
```ts
    offWindows = run.sdk().modules.register(PROFILE_WINDOW_OWNER, { windows: { main: {
```
В карточке — аватар, имя и короткий список строк игры: **`PROFILE_STATS` в `src/screens/index.ts`**
(рядом с `MENU` и `LOCALES`) — подпись (ключ строк) и откуда значение:
```ts
export const PROFILE_STATS: readonly ProfileStat[] = [
  { label: 'screen.profile.levels', value: 'levelsCompleted' },
  { label: 'screen.profile.best', value: 'highestScore' },
];
```
- `levelsCompleted` — пройденные уровни (шаги `progress_main`, из прогресса сессии, без запроса);
  любое другое имя — поле сводки профиля `sdk.profile.get()` (`highestScore`, `totalScore`,
  `gamesPlayed`, `gamesWon`, `score`).
- Строка без значения (нет данных, пусто, «—») не показывается. Подписи — слева, значения — справа
  одной колонкой во всех размерах (сетка `PROFILE_CSS` в `src/shell/skin.ts`).
- Список держать коротким и про игру. Стоковое окно кита `profile` — окно разработчика: все
  системные поля с прочерками, реферальный код, язык, страна, друзья, доля побед, поле «ID
  игрока», кнопка «Обновить профиль» (она только перечитывает тот же профиль) и JSON. Шаблон его
  не показывает: карточка рисуется своим компонентом с тем же именем `profile`, лист скина
  `profile` к ней применяется.
- Имя — из профиля; у гостя без имени — `shell.profile.player` («Player {gid}»). Имя гостя задаёт
  сервер профилей (на стенде — «Игрок N» на русском независимо от языка игры): это данные игрока,
  не текст игры.

## Настройки
Стандартное окно `ui.settings` (`src/shell/windows/standard.ts`, `withSettings`):
- язык — опубликованные языки игры (`LOCALES`, [localization.md](localization.md)); выбор уходит в
  l10n, звука и музыки нет:
  ```ts
        void sdk().l10n.setLocale(tag).catch(() => undefined);
  ```
- строка аккаунта: у гостя «Вы не вошли» и кнопка «Войти», у вошедшего — его ManyPlay ID.

## Вход ManyPlay ID
Кнопка аккаунта настроек (`data-testid="settings.account"`) шлёт намерение `open` с
`{ id: 'account' }`. Кит его сам не обрабатывает: стандартное окно отдаёт такие намерения в
`onAction`, которого никто не передавал, поэтому раньше кнопка ничего не делала. Теперь
`withSettings` закрывает настройки и открывает окно ManyPlay ID (`src/shell/windows/account.ts`):
- гость — вход: кит `login` (`@manygamescorp/ui-kit/services/login`) поверх потока входа core
  (`createAuthFlow`, `@manygamescorp/core/auth-flow`): почта → код → подтверждение;
- вошедший — окно аккаунта того же компонента (ник, выход).

Смена игрока идёт обычным путём SDK: `sdk:reload:required` → обложка, сброс прогресса;
`auth:playerChanged` → инвентарь, главный экран, вход дня с одним чтением прогресса
(`bindPlayer` в `src/boot/start.ts`). Окно входа ждёт, пока игра готова для нового игрока
(`waitForPlayerReady`), и закрывается само. Это модуль оболочки, а не SDK: SDK останавливает свои
модули на время смены игрока, поток входа должен это пережить.

Что нужно от платформы (по коду core rc.30, на стенде проверено только открытие окна):
- вход по почте — ничего: окно читает провайдеров (`GET /v1/auth/oauth/config`), почта доступна
  всегда; ссылка из письма ведёт на сайт id (`https://id.*/l/…`), не в игру — адреса возврата
  игре не нужны;
- Google — включённый провайдер в настройках входа приложения (`webClientId`, платформа `web`)
  и адаптер `providerAdapters.google` в `createSdk`; шаблон адаптер не передаёт, Google не
  предлагается;
- Facebook — включённый провайдер с `appId` и платформой `web`; запрос идёт с cookie id, поэтому
  API id должен разрешать origin игры (CORS с credentials);
- внутри портала ManyPlay вход идёт через портал (`sdk.portal.openId`); шаблон портал в
  `createSdk` не передаёт — всегда своё окно.

## Как проверить
`tests/browser-startup.mjs`: окно профиля — строки в две колонки, без id, кодов и прочерков, без
кнопки обновления; настройки → «Войти» → экран входа ManyPlay ID и запрос провайдеров (почта не
вводится). Галерея: виды `profile` (проверки строк) и `login`.
