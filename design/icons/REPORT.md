# Иконки Iron Burrow — сборка

39 готовых изображений сохранены без новой генерации: 29 значков оболочки, 4 бустера, 5 предложений и иконка приложения. Собран прозрачный атлас 6×5, порядок ячеек строго из docs/skin/map.json (последняя ячейка пустая). design/system/**, SDK, UI Kit, обвязка и пакеты проекта не изменены.

## Размещение и решения

- Оболочка: assets/ui/icons/<ключ>-2x.png, 96×96; предметы: assets/ui/items/<ключ>-2x.png, 320×320; предложения: assets/ui/offers/<ключ>-2x.png, 320×320; приложение: assets/game/app_icon-2x.png, 1024×1024. Версия 1x вдвое меньше. Имена ключей сохранены, включая offer-. Манифест содержит точные пути для подключения, без копий под альтернативными именами из ранней таблицы ГДД.
- Атлас: assets/ui/game-icons-2x.png 576×480, assets/ui/game-icons.png 288×240. Ячейка соответственно 96/48 px. Координаты 2x из карты нельзя применять к 1x без деления на два. Изменения подключения скина принадлежат следующему шагу.
- У исходников 1254×1254: версии 2x механически уменьшены до контрактных размеров. Один результативный запуск npm run assets -- --webp=90 создал все 1x и WebP. Более ранний запуск на пустом assets был холостым из-за исправленной ошибки пути импорта sharp и ничего не записал.
- genCount = 0 означает вызовы в этом шаге сборки. Исторические счётчики и точные исходные промпты не предоставлены; в prompt записан явно помеченный brief сборки, не выдуманный журнал генераций. Источник Codex указан по сообщению владельца, а не выведен из PNG.
- coins и gems сохранены как служебные ключи карты: изображения ящика и осколка Ядра. Валюты в игру не добавлены.

## Визуальная оценка PNG

CONTACT_SHEET.png просмотрен как изображение: каждый id показан в цвете, сером и при 24 px. Сталь/бирюза, оранжевый жар, янтарные награды и верхне-левый свет согласованы с библией и STYLE_REF. Один предмет доминирует внутри каждого значка, фоны прозрачны; у приложения фон непрозрачный. Молния, флаг, замок, антенна, шестерня и треугольник читаются силуэтом. Четыре бустера различаются куполом, кольцами, плитой и корпусом. Предложения различаются контейнером и наполнением. Медали различаются формой (круглая зубчатая / прямоугольная / трёхлопастная), в том числе в сером. Намеренное сходство ящиков coins/gift/shop соответствует карте. Мелкие заклёпки на 24 px теряются, основные массы сохраняются. На растровых предметах нет надписей. Явного брака для перегенерации нет. Независимое ревью экранов и формальная измеренная читаемость не проводились.
