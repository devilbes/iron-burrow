# schemas

Схемы разделов записей этого приложения, как их отдаёт сервер: `index.json` — список разделов со
схемами, `<scope>.json` — JSON Schema, по которой сервер принимает запись раздела, с её версией
(`ui.hud.json`, `levels.main.json`; для разделов по шаблону годится и имя-шаблон `levels.*.json`).
Их сохраняют в начале работы над игрой; в шаблоне каталог пуст. `npm run records` проверяет файлы
`configs/remote/` по этим схемам ([configs.md](../docs/platform/services/configs.md#проверка-до-записи)).
В сборку каталог не входит.
